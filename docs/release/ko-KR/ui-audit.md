PHAT 기본 프로그램에서 사용하는 기본 운동 27종의 한국어 표시명을 추가했다. 사용자가 바꾼 종목명과 사용자 기구 이름은 그대로 표시한다. 기본 운동 27종 외 전체 기본 운동 사전의 한국어 번역이 완료되었다는 뜻은 아니다.

케이블 암 풀다운은 기본 이미지 라이브러리에 정확히 같은 동작이 없어 프로그램 담당이 사용자 운동으로 유지한다. 다른 동작의 이미지로 대체하지 않는다. 이 종목은 기본 아이콘을 사용한다.

## 데이터 호환성 확인

- `Exercise_fullName`, `Exercise_buildName`, `equipmentName`, 운동 ID 및 기구 ID는 그대로 유지했다. Liftoscript와 임포트·익스포트에 쓰이는 표준 이름은 바꾸지 않았다.
- `Exercise_nameForDisplay`, `Exercise_nameWithEquipment`, `Exercise_equipmentNameForDisplay`, `localizedEquipmentName`은 화면 표시를 담당한다. `Exercise_nameWithEquipment`의 추가 호출부는 설정의 화면 정렬 및 변경 설명 로그다.
- `Stats_name` 호출부는 `statsList.tsx`, `screenSleepNutrition.tsx`, `graphStats.tsx`, `modalGraphs.tsx`의 화면 제목·선택값·범례다. 현재 소스 검색에서 CSV/API/프로그램 serializer 호출은 발견되지 않았다. 측정값 키는 변경하지 않았다.
- codebase-memory 지침의 Verify 범위로 소스를 확인했다. 이 실행 환경에는 그래프 도구가 없으므로 인덱스 생성 시점·범위는 확인하지 못했고, 지정 파일과 호출부의 직접 소스 검색을 근거로 했다.

## 확인 결과

### 실제 브라우저 확인 (2026-10-24)

`npm run build:prepare`는 통합 검증 담당이 수행했다. 이 담당은 같은 앱을 중복 빌드하지 않고 webpack 개발 서버(HTTP `localhost:8080`)에서 실제 Chromium 화면을 확인했다. 브라우저는 합성 프로그램만 사용했고 계정/API·분석 요청은 차단 응답으로 처리했다. fixture는 `output/playwright/ko-ui/ko-ui-synthetic-program.json`이며 긴 한글 제목과 운동명을 포함한다. 예제 프로그램을 불러올 때 프로필 단위 변환 안내에서 취소해 브라우저 표시 단위는 lb였다. 제품 기본 단위나 원본 프로그램 데이터는 변경하지 않았다.

## 출시 전 남은 확인

- 실제 Android 또는 에뮬레이터에서 320/360dp 화면, 큰 글자, 긴 한글 운동명, 키보드 표시 중 화면 스크롤을 확인해야 한다.
- 운동 일정 시간 입력 및 저장 버튼 접근성은 별도 일정 담당·통합 시각 검사 범위다.
- 전체 앱의 기본 운동 사전, 고급 편집기·도움말 등 미점검 화면은 별도 번역 확인이 필요하다.
- 이 문서의 PASS는 지정된 UI 수정과 계약 검사 범위이며, 한국 앱스토어 출시 승인·정책 충족을 뜻하지 않는다.
