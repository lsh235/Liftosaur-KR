# 한국 출시 진행 계획

기준일 2026-10-24 (Asia/Seoul), 기준 v158.0. 상위 에이전트는 조정·판정, 실제 수정·검증·문서는 담당 하위 에이전트가 수행한다.

## 1차: v159 로컬 전용 후보

1. 원본 인증/동기화/구매 API와 네이티브 분석/진단/결제/OAuth/FCM/OTA를 기본 차단한다. 이전 계정·로컬 기록은 삭제하지 않고 미지원 화면을 한국어로 안내한다. 원격 미디어는 별도 범위로 유지한다.
2. PHAT 29개 운동 슬롯·30세션·주차별 예시 중량/횟수, 불량 입력 시 기존 기록 무변경, 워밍업 제외 볼륨과 목표/실제 MD 왕복을 검증한다.
3. 한글 글꼴·긴 이름·키보드·일정 입력·큰 글자·번역 누락을 개선하고 모의 화면과 실제 기기 검증을 구분한다.
4. 관련 모델/렌더/타입 검사 후 새 SHA의 서명 APK 빌드·설치·시작 증거를 확보한다. `workflow_dispatch`는 후보 검사와 14일 보관 아티팩트 업로드만 하며, `v*` 태그 푸시만 GitHub Release를 공개한다. 통합 판정 전 태그를 만들지 않는다.
5. 기존 KR 서명·app ID를 유지한 업데이트와 전체 백업 복원에서 사용자 데이터 비교를 수행한다. 통과 후보만 테스트 배포 여부를 판정한다.

## 2차: 별도 Play 후보

운영자 소유 새 패키지·명칭·도메인·실제 연락처·수익화 범위를 확정한다. 파일을 통한 기존 KR 기록 이전 및 두 앱 공존을 검증한다. Health Connect·정확한 알람·전경 서비스·카메라를 기능별로 최소화하고 거부/취소/삭제 동작을 확인한다. 실제 사실과 맞는 한국어 정책·공개 URL·스토어 선언을 마련한다. 자산별 권리와 AGPL·패키지 고지를 확인한다. 서명 AAB, 16KB 페이지 지원 등 제출 도구 검사와 Play 사전보고서, 해당 계정의 비공개 테스트·심사 증거를 확보한다.

구현→관련 검증→독립 검토를 반복한다. Gate 실패 후 원인 수정·재검증은 최대 **2회**다. 같은 원인을 확인 없이 반복하지 않는다. 미해결이면 FAIL/NOT RUN과 재현·필요 환경·담당자를 기록하고 진행 가능한 작업을 계속한다. 기술 후보가 통과해도 C07/C08 미완료이면 한국 일반 공개는 NO-GO다. 버전 이름을 바꿔 Gate를 우회하지 않는다.
