현재 연결된 계정 — 최근 15분 내 인증된 MCP 도구 요청
등록된 계정 — 기록이 있는 계정
개인정보 안내 마스킹된 MCP 요청 인수에 운동 내용이 포함될 수 있습니다. 인증 비밀값은 최선의 노력으로 마스킹하며, 응답 본문은 저장하지 않습니다.
요청 데이터 안내MCP 도구 인수에는 운동 기록과 건강 정보가 포함될 수 있으며 지정된 관리자에게 최대 30일간 표시됩니다. 서버는 민감한 키와 흔한 토큰 패턴을 최선의 노력으로 마스킹하고 요청을 최대 8KB로 제한합니다. 마스킹이 모든 비밀값을 찾아내지는 못할 수 있습니다. 응답 본문은 저장하지 않습니다. 배포 후 수집된 요청만 표시됩니다.
